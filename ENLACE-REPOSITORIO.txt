 COMO EJECUTAR EL PROYECTO (para el evaluador)
-------------------------------------------------------------------------------

 Requisito: PHP 8.0 o superior. No requiere Composer, ni MySQL, ni
 dependencias externas.

   1. Descomprimir el proyecto.
   2. Abrir una consola dentro de la carpeta sistema-showroom-api.
   3. Cargar los datos de ejemplo:

        php scripts/sembrar-datos.php

   4. Levantar el servicio:

        php -S localhost:8000 -t public public/index.php

   5. Abrir en el navegador:

        http://localhost:8000/cliente/index.html      Cliente de demostracion
        http://localhost:8000/api                     Indice de los 37 servicios
        http://localhost:8000/api/salud               Estado del servicio

 Cuentas de prueba:

        admin    / Admin2025      administrador (acceso total)
        asesor   / Asesor2025     asesor (clientes, cotizaciones, pedidos)
        consulta / Consulta2025   consulta (solo lectura)

 Para ejecutar las pruebas automatizadas:

        php scripts/pruebas.php
